 
# Coach Landing Page

This project is a custom landing page for WordPress, developed with a strong focus on design and functionality. The design was crafted from scratch, with particular attention to responsiveness and modern web standards. Built using Bootstrap 5, this landing page combines smooth animations, interactive elements, and optimized assets to create a seamless user experience.

## Link to the project:
[Link](https://coach-5n31wiacw-slavas-projects-d697b849.vercel.app/)

## Key Features

- **Custom Design:** The entire design was created specifically for this project, ensuring a unique and tailored look.
- **Modern Tech Stack:** Utilizes Vite for fast builds and development, along with modern tools like SCSS for styling, and Sharp for image optimization.
- **Interactive Elements:** Features such as scroll-triggered animations, modals that appear on scroll, and custom sliders provide an engaging user experience.
- **Optimized Performance:** With tools like `vite-plugin-image-optimizer` and `autoprefixer`, the landing page is built to load quickly and work across all modern browsers.

## Dependencies

- **Bootstrap 5:** The foundation of the layout and components.
- **Bootstrap Icons:** A collection of SVG icons to enhance the UI.
- **ScrollReveal:** For creating smooth, scroll-based animations.
- **Glide.js:** A lightweight and responsive slider library for showcasing content.

## Development Tools

- **Vite:** Ensures fast development and optimized builds.
- **SCSS:** For writing maintainable and scalable CSS.
- **Sharp:** Used for high-performance image processing.
- **SVGO:** Optimizes SVG files to reduce file size without losing quality.
